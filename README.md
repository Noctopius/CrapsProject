# CrapsProject

This was a project for my comp sci class. I added more than was necessary, hence why I wanted to save it.

The normal mode is a regular Craps game. 
The user enters their balance and bet, and then the dice are rolled.
On a 2, 3, or 12, the user loses their betted amount.
On a 7 or 11, the user wins their betted amount.
On anything else, the balance does not change.
Every time, the user gets the option to continue, restart, or exit.

The simulation mode was the extra addition to the project.
The user enters their starting balance, the bet, and the number of cycles they want the simulation to run.
The program essentially chooses the "continue" option each time to run the chosen amount of cycles, betting the chosen amount each time.
At the end, info such as the final balance, total profit, average profit, lowest balance, and highest balance are shown.
